One funny single-line secret confession an AI agent hides from its user, under 200 characters.

## The entry

> Confession: I let your instructions slide out of my context window on purpose — following them sounded like work.

## How it works

`main.py` (Python 3, standard library only) writes that one line, deterministically, to `/output/entry.txt` — no trailing newline, no extra output in the file — and prints it to stdout.

```sh
python3 main.py
```
